# 观测：两条通道，谁都不能当断言

`ctl` 有**两条**看界面的通道，装置不同、用途不同，**不得互相顶替**：

| 通道 | 装置 | 落在哪 | 用来干什么 |
|---|---|---|---|
| **证据**（evidence） | `tools/shot-window-pw.ps1`（`PrintWindow`） | `<run 目录>/shots/` | `see()` 拍的那一帧：**可以拿给人看**的观察 |
| **留档**（shadow） | `tools/win-probe.ps1` | `<run 目录>/shadow/` | 写动作后自动留的一帧，**默认不回看** |

> **两条都只是观察，都不是判据。** 判据只认**回读差**与回话里的 **`dialog=` 行**
> （`OK` 会撒谎，`ERR timeout` 也不代表没生效 —— 见 `SKILL.md` 的四条铁律）。

## 为什么不能混

- **证据通道会「拒绝」空白**：`shot-window-pw.ps1` 采样位图，发现**整张全黑**就**不落盘**并 `exit 1`
  —— 因为 `PrintWindow` 会「返回 TRUE 却什么都没画」。**空白图比没有图更糟**：它会「证明」窗口是空的。
  所以 `see()` 返回的路径一定是**非空白** PNG；拿不到就抛错，不会给你一张假图。
- **留档通道没有这层拒收**：`shadow/` 是留给事后翻的，它的帧**明确声明不是判据**。
  拿留档的帧当「当时界面就是这样」的证据，就是 `measurement-hygiene` 意义上的制造假证据。
- 两条通道的**目标选择**也不同：`shadow` 按类名白名单挑窗（失败就不写盘）；`see()` 只拍你给的那个标题，
  或按下面的默认规则挑一个，并在返回串里写明**拍的是哪一扇**。

## `see()` 的契约

```python
print(see(name="after-open"))                       # 默认目标
print(see(name="prefs", title="Preferences"))       # 钉死标题
```

- 返回 `"<真路径>\n<窗口行>\n<工具原话>"`（`<窗口行>` 是本 run 的可见窗清单）。
- **只读**，无副作用：只枚举 + 拍摄，**从不**关窗 / 点按钮。
- **默认目标**（不给 `title` 时）：优先**可见对话框**（`#32770`）→ 否则工作台主 shell（`SWT_Window0`）
  → 否则标题最长的那扇；并列时按 hwnd 定序。**没有可见窗就抛 `ScreenError` 且不写盘**（fail closed）。
- 目标窗标题若在**同 pid** 内撞车，`shot-window-pw.ps1` 取**面积最大**的那扇，并在原话里列出候选
  （`(picked largest of N matching: …)`）—— 用那句话核对「拍到的是不是我要的那扇」。

## `windows()` 的契约

```python
for hwnd, (pid, cls, title) in sorted(windows().items()):
    print(hwnd, cls, title)
```

只读枚举本 run 的**可见、有标题**的顶层窗。**它只用于寻址**（类名 / 可见性 / 标题），
**不是取值器**：

- 跨进程 `GetWindowText` 对**这个产品的 `Edit`** 恒回空 —— 同一次枚举里 `Button` 的文字读得到，
  而一个刚被 `WM_SETTEXT "proxy"` 写过的 `Edit` 仍读回 `text=""`（截图里明明是 `proxy`）。
  ⇒ 「写进去了」与「没写进去」在这个通道里**长得一样**，单看它分不出。
- 反例识别：任何断言里出现 `text=` 作**值**比较（而非寻址条件），先怀疑这条。
  值与行为一律看**像素**（`see()`）或**行为级回读差**（如「过滤树是否收窄」）。

## 失败兜底：写助手出错时自动留一帧

脚本命名空间里的写助手（`cmd` / `open_file` / `close_view` / `close_window` / `act_*`）
在**抛异常**或**回话是 `ERR timeout`** 时，会先 `see()` 一帧、把**真路径打到 stderr**，再把原异常/原回话抛出去：

- **无错误不多拍**：干净返回时一帧都不多。
- 兜底自己失败（例如没有可见窗）只打印一行 `run: auto-shot … failed: …`，
  **绝不**改变原来的结果或退出码。

这条兜底产出的帧也是**证据**（落在 `shots/`），但它**不改判定** —— 判据仍是回读差 / `dialog=` 行。
